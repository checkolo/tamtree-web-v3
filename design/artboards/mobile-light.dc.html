01 — the primitives

Some work wants a script.
Some work wants a crew.

Pipelines are deterministic DAGs — the same steps, in the same order, every time. Sync, ETL, billing: things that should be boring.

Crews are multi-agent teams — a lead agent decides each move. Research, triage, support: things with no script.

Nest them freely: a pipeline step can be a crew. A crew can call a pipeline as a tool. One engine underneath.
